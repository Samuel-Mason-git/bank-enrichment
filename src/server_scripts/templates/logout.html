Signing out

This dashboard uses HTTP Basic Auth, which has no real server-side session to end — your browser just remembers the password you typed in and resends it automatically.

To fully sign out, close this browser tab or window. Simply navigating back to the dashboard will log you straight back in using the credentials your browser already has cached.
